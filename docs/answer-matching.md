# 答案判定与复习列表

参考：[Duolingo 对可接受答案变体的说明](https://blog.duolingo.com/how-user-reports-improve-course-content/)、[Moodle 短答题设置](https://docs.moodle.org/en/Short-Answer_question_type)。这些系统采用可接受答案集合，并分别处理大小写与题型要求；缩写、词序和同义表达需要明确的变体规则，不能简单采用文本相似度放行。

实现：统一全角字符、大小写、空白、弯直撇号、句子标点；保留小数点。支持常见缩写与完整形式，例如 I'm/I am、don't/do not、can't/cannot、I've/I have、I'll/I will。代词 's 对 been/got 使用 has，其余使用 is；其他歧义和同义改写继续由题目的可接受答案列表指定。不会忽略否定、时态、词序、漏词、单词拼写，也不采用编辑距离把 waiter/water 之类差异判对。

历史答题原始记录保留。错题本按当前判定规则排除已接受的等价答案。答对或手动移出的题不再显示为待复习；主动移除可撤销，今后再次答错会重新出现。移除动作沿现有私有事件流跨设备同步，不涉及数据库权限变更或永久删除记录。

单词本：课程词汇，每页30词，默认折叠例句，支持中英文搜索、发音及展开词条。

生词本：主动收藏的词，独立入口，复用已有收藏记录。从本课单词和课文点击词语查看词条，再加入；提供词条、语境例句、发音、单词听写、回课文与移出操作。同词跨课收藏去重展示并保留来源。课程词汇和学习成绩不因移出生词本而删除。
