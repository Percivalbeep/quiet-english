# 慢慢说 · Everyday English

正式网址：[慢慢说](https://percivalbeep.github.io/quiet-english/)

为工作间隙戴耳机、不能频繁开口的成人初学者设计。建议每天20—30分钟，可拆成4次短练；不强制拖延时间。实际耗时随复听和回忆需要而变。

## v0.2：词汇与生活场景一起学

前4周共24个学习日，每课包含：

- 8个关键词：发音、中文含义和语境例句；熟词会在新场景里复用。
- 5个核心表达和一条简短语言规律。
- 6轮情境对话，英文原文及可展开的中文辅助。
- 一篇生活短文或预订信息，配理解任务。
- 30道分段练习：16道词义/拼写/听词题、5道基础表达题、4道填空/组句题、2道对话题、3道阅读题。共720道。
- 独立的晚间开口卡，不作为白天任务的强制条件。

单词本覆盖148个不同词语或常用词组，分别显示认义、听辨、拼写的最近练习结果。部分词语只做过其中一种练习时，其余维度显示“未练”，不假装已经掌握。

复习先以约1、3、7、14、30天为初始间隔。每次8道短练，轮换词语并优先带回近期错误。答对比例达到80%则延长间隔，否则回到约1天。这是可调整的教学规则，不能换算为CEFR等级。

原有答案、首次成绩、留言和开口自记都保留。课程扩充后，旧课的5道题仍然保留，新内容需要补练；新版完成记录另外追加，不覆盖历史。暂停后从未完成题继续。

## 当前发音与个人资料

当前课程使用399段预先生成的系统英语录音，学习设备直接播放MP3，无需依赖Safari实时朗读。单词、例句和表达使用Samantha；24课完整对话按A/B角色使用Samantha和Daniel，换人留约0.55秒停顿。Qwen素材只保留历史，不再用于播放。用户自选而不在素材库中的词仍调用设备朗读，并有启动超时提示。

登录后在“我的空间 → 我的账号”修改昵称、上传或移除头像。头像在浏览器裁成192像素正方形JPEG，与昵称一起保存到仅本人可读写的 qe_profiles 表，不放入登录令牌、不新建公开存储桶、不修改成员角色权限。其他设备重新打开时读取本人资料。登录邮箱仍是登录标识，昵称不是独立登录名。

界面使用黑白灰；平板卡片两列显示，短屏侧栏省去装饰区并可滚动，装饰使用CSS线条以避免iPad彩色emoji。

## 历史Qwen音频

已使用现有本地Qwen3-TTS-12Hz-1.7B-CustomVoice模型（MLX 4-bit）和Aiden音色生成285段独立的词汇、短句及情境对话音频。模型只用于离线制作素材；学习网页无需运行模型、调用收费语音接口或连接这台电脑。

短句和对话经过不改变音高的初学者语速处理，页面另有慢速播放。词汇/表达的同一文本共用音频。全部音频经过解码检查；生成来源及处理信息见 `assets/audio/qwen-provenance.json`。旧版m4a保留在源文件历史中，但新版播放入口不再选择它们。

这不是多人真人对话录音；情境对话使用同一合成音色示范不同轮次，不冒充真人。模型及许可见 [Qwen官方仓库](https://github.com/QwenLM/Qwen3-TTS)。

## 她怎样自行注册

1. 你用陪练账号登录，打开“布置与反馈”。
2. 点击“生成学习者邀请”，复制链接，只转发给受邀学习者。
3. 她打开链接，邀请代码自动填好，自行设置昵称、邮箱和至少8位密码。
4. 注册后直接加入这个学习空间，不需要管理员替她设置密码。
5. 你在“当前查看的学习者”中选择她，即可分别布置任务、看进度和留言；选择会记在当前浏览器。

邀请一次有效、7天过期。只有陪练可以发邀请，任何人都不能通过注册表单自行升级为陪练。不同学习者不能互看记录或成员资料；陪练可查看本家庭受邀学习者。

邀请代码放在链接片段中，不随网页请求发送给静态托管方；数据库只保存其哈希。注册时经加密连接将代码交给Supabase验证，成功后从地址栏移除。网页源代码、公开连接key和课程在GitHub公开；密码、私有邀请表和学习记录不在仓库中。

当前按家庭使用需求，已启用“邀请注册后直接使用”，关闭首次注册邮箱确认。账号本身仍需邮箱和密码登录，学习空间还需要有效邀请。密码找回邮件服务不在本次范围内，密码请本人保管。

## 同步与本机记录

GitHub Pages提供静态网页，Supabase提供登录和私有数据存储，无需自建服务器。

- 答题后立即尝试上传，页面在前台时约每5秒检查新增记录。
- 切回前台、恢复网络时立即检查；网络故障时退避重试。
- 不可修改的UUID事件用于去重与合并，不会让两个设备的整个进度文件互相覆盖。
- 每12轮做一次全量核对，补上可能延迟提交的记录；只有本机保存成功后才推进游标。
- 学习者名单约每30秒刷新，也可手动刷新。它与答题记录的5秒检查分别处理。
- 关闭网页或浏览器挂起后，不保证后台持续同步；下次打开并登录后继续补传。
- 本机队列使用浏览器存储。请定期导出备份；试用与正式账号分开，不会自动混入真实成绩。
- 已加载的练习可在断网时作答暂存；尚不承诺关闭网页后能完整离线重开。

## 维护与部署

需要Node.js 22+和Python 3；网页没有npm运行依赖。

```sh
npm run dev
npm run check
npm test
npm run build
```

本机预览地址为 `http://127.0.0.1:4173`。不要双击HTML文件；直接打开文件时会给出明确提示。

GitHub Actions只发布 `dist/`。构建会为模块及依赖、样式、公开配置生成内容版本，避免更新后仍运行旧登录程序。`config.js`只包含Project URL和publishable key；构建拒绝管理员密钥。

已有项目升级执行 `supabase/registration.sql`；它保留原数据，允许一个陪练跟踪多名学习者，并收紧学习者之间的可见范围。全新安装依次运行 `schema.sql`、成员初始化示例及 `registration.sql`。不要重复运行成员初始化脚本来覆盖已有成员。

现有Qwen环境及模型在相邻演讲项目的忽略目录中，未打包进网站。维护者重新生成时使用：

```sh
../consseau-public-speaking-assistant/.work/qwen-venv/bin/python scripts/make-qwen-audio.py --model ../consseau-public-speaking-assistant/.work/qwen-models/CustomVoice
python3 scripts/pace-audio.py
```

中间音频只留在忽略的 `.work/`。如更改音色或生成规则，应更新音频路径的版本盐，避免旧音频缓存。

正式数据库已运行 `verify-rls.sql` 和 `verify-registration.sql`。后者验证了两个新增学习者的邀请入组、固定学习者身份、一次性邀请、重复提交、互不可见和陪练可见；测试用户没有密码或会话，全部测试写入最终回滚。匿名REST读取学习表被拒绝。

页面上已跑通完整30题、暂停继续、词序组合、短文结算、单词本和390像素手机注册表单。受邀者的真实邮箱/密码注册应由本人完成；网站不会自动替她创建密码。

当前内容是前4周的入门课程，后续课程应依据她的实际表现迭代。平台不把选择题成绩换算成真实口语流利度，不提供自动发音评分。
