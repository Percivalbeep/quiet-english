# 慢慢说 · Everyday English

面向成人入门者的生活英语练习空间。为上班时戴耳机、无法频繁开口的使用场景设计。

## 当前交付

- 24个学习日，覆盖问候、求助、数字、购物、点餐、交通、酒店及简单问题处理。
- 72段示范音频（随网站提供，不依赖在线语音识别）。
- 每课3个表达、5道静默练习、独立的晚间开口卡。
- 首次作答与重试分开记录；开口自记不算口语达标。
- 间隔复习、成长记录、陪练布置及留言。
- GitHub Pages静态网页＋Supabase登录与数据库适配。
- 答题后触发上传；页面可见时每5秒检查；切回页面和网络恢复时立即检查。
- 本机持久待上传队列、失败重试、UUID去重、备份导入与导出。

**已配置正式云端项目地址与公开连接key，未登录时进入本机试用。试用不会跨设备同步。** 正式账号需完成成员初始化；请使用两个独立账号。模拟接口测试通过不代表线上数据库权限已经验证。

正式网址：https://percivalbeep.github.io/quiet-english/

已在正式数据库执行成员初始化和 `supabase/verify-rls.sql`：学习者写入、陪练读取与反馈、角色分离、跨家庭写入隔离及不可修改历史记录均通过；验收写入已回滚。匿名REST请求读取两张表均返回401拒绝。登录及页面间同步仍以实际账号验收为准。

## 本机打开

要求Node.js 22或更新版本、Python 3。不需要安装npm依赖。

```sh
npm run dev
```

打开终端显示的 `http://127.0.0.1:4173`。不能通过双击HTML文件运行模块。首次页面以学习者试用身份打开；在“我的空间”可切换陪练试用。真实账号的身份由数据库决定，不能通过界面切换。

## 建立正式学习空间

### 1. Supabase

1. 在自己的Supabase账号中新建项目，项目密码由本人设置和保管。
2. 在SQL Editor运行 `supabase/schema.sql`。它建立成员表、不可修改的事件记录表、索引和家庭级权限。
3. 在Authentication → Users中创建两个独立的邮箱/密码账号并确认邮箱：一个学习者、一个陪练。密码由本人设置，不写进代码或聊天。
4. 复制两个用户的User ID，替换 `supabase/members.example.sql` 中两个占位UUID，然后运行。一个家庭只设置一个学习者和一个陪练。
5. 不开放公共注册；账号开通、密码重置和成员调整先在Supabase后台管理。
6. 从项目设置取得Project URL和**publishable key**。只使用公开key，绝不使用secret/service_role或数据库密码。

### 2. GitHub Pages

1. 建立 `quiet-english` 仓库，把本文件夹提交到 `main` 分支。免费账号使用公开仓库时，网站代码和课程可见；个人学习数据不在仓库中。
2. Settings → Pages → Source选择 **GitHub Actions**。
3. Settings → Secrets and variables → Actions → Variables添加：
   - `SUPABASE_URL`：形如 `https://项目标识.supabase.co`。
   - `SUPABASE_PUBLISHABLE_KEY`：项目公开key。这是公开配置，无需使用管理密钥。
4. 运行“Publish learning space”工作流。它先检查并测试，再只发布 `dist/` 中网页、课程和音频。
5. 工作流成功后，以实际返回的Pages网址为准。不要把预估网址当成发布成功。
6. 两人打开同一网址，分别登录各自账号。

也可直接修改 `config.js` 的两项公开配置后发布。构建时，非空的仓库变量优先。

### 3. 上线验收（连接项目后必须完成）

1. 两个不同设备分别登录学习者、陪练。学习者答一道题，陪练前台等待一轮检查，应看到该条记录。
2. 陪练布置当天课程并留言；学习者切回页面，应看到安排。
3. 学习者断网答题，检查待上传状态。刷新可能无法离线加载网页；保持页面打开，恢复网络后检查补传，重复同步不重复计数。
4. 刷新和重新登录后记录仍在；退出不会清空待上传数据，重新登录同一账号后补传。
5. 使用无成员身份的测试账号验证不能读取或写入；匿名请求不应访问学习表。
6. 使用另一家庭的测试账号验证无法读取本家庭记录。学习者不能新增陪练留言，陪练不能伪造学习者答案。
7. 在她实际使用的手机、电脑、网络环境测试音频和两项服务可访问性。

## 同步设计与边界

- 网页本身不接收服务器端写入，所有私有记录直接访问Supabase，访问由登录令牌、数据库授权与RLS控制。
- 事件是追加记录，唯一UUID作为去重键。来自两台设备的答案不会用整个进度文件互相覆盖。
- `seq` 是服务器生成的递增游标；首次登录拉取历史，后续读取新增记录。每12轮做一次全量核对，补上可能延迟提交的记录。每次最多500条并分页。只有本机成功保存，才提交新游标。
- 网络失败时5、10、20、40、60秒退避；重新联网或切回前台会立刻尝试。同步过程有超时，不重叠启动多个轮询。
- 页面关闭或浏览器挂起后，没有持续后台同步承诺。最后一次待上传内容会在下次打开并登录时继续同步。
- 本机队列用localStorage，适合当前文本记录规模；不存录音大文件。浏览器清理、隐私模式或存储空间不足可能影响数据保留，请定期导出备份。
- 第一版没有Service Worker，因此不承诺关闭网页后仍能完全离线打开课程。网络中断时已加载的练习仍可作答并暂存。
- 学习日期按当前设备当地日期计算；旅行跨时区可能影响“今日安排”和日历归属。
- 正式空间与试用空间隔离；不会自动把试用成绩导入正式账号。
- 认证令牌保存在本浏览器。共享电脑使用完请退出。网页不加载第三方脚本、字体或分析追踪。
- 免费服务的额度、可用性和暂停策略以账号当时显示为准，不承诺永久零费用。

## 教学节奏

白天约15—20分钟，可拆成3次5分钟：听3句 → 做5道练习 → 复习旧课。晚间2—5分钟开口选做，每周尽量安排一次真实对话；长期口语目标仍需要实际说话练习。

1、3、7、14、30天是初始间隔。复习5题答对至少4题时延长间隔，否则回到约1天；这是可调教学规则，不是经个体校准的科学阈值。首次答案保留，错误可通过后续练习巩固。

当前24课是第一轮可试用的入门内容，尚不包含一年完整课程、自由写作批改、自动发音评分或正式CEFR测评。听懂/认出表达，不应等同于会在真实环境中表达。老师可选择已有课程布置；创建全新课程暂时通过 `app/curriculum.js` 编辑，并同步生成音频。

## 检查与打包

```sh
npm run check
npm test
npm run build
```

构建结果在 `dist/`。测试涵盖首次成绩、复习间隔、离线补传、重复去重、并发合并、两个账号的接口交互、令牌刷新、游标提交和音频存在性。接口交互使用内存模拟服务；实际Supabase数据库与RLS必须在上线后验证。

macOS维护者修改示范句后，可使用 `python3 scripts/make-audio.py` 生成音频（需要系统英语Samantha音色和ffmpeg）。普通学习者和GitHub构建均不需要生成音频。
